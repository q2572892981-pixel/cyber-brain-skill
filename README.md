# Cyber Brain Skill v0.1

把一段很长、很乱的录音转写或聊天记录，变成少量真正值得长期记住的“个人记忆”。它会过滤寒暄、语气词、重复和无关内容，保留会改变语义的细节，并把内容整理成：

> 事件 → 原判断 → 新发现 → 我的观点 → 办法/行动 → 待验证

它还会做两件普通总结工具不一定会做的事：

- 检查新内容和旧记忆是否重复或冲突；
- 在未来回答“按照过去的我会怎么做”时，明确区分历史事实和 AI 推断。

## 适合谁

适合想把聊天、访谈、录音转写、复盘和日常思考，慢慢沉淀成个人判断系统的人。

## 快速使用

1. 把 `SKILL.md` 放进你的 Codex skills 目录，或在支持 Skills 的工具中加载这个文件夹。
2. 提供一段转写文本，并说：“用 Cyber Brain 提取值得长期记忆的内容。”
3. 如果有旧记忆，一起提供，让它做去重和冲突检测。

也可以直接说：

- “提取值得长期记忆的内容。”
- “把这段和我的旧记忆合并，告诉我哪些被更新了。”
- “根据这些记忆，按照过去的我会怎么做？”

示例提示：

```text
用 Cyber Brain 处理下面这段录音转写。
只保留值得长期记忆的内容，不要把寒暄和重复记进去。
如果发现和旧记忆冲突，请单独列出，不要擅自覆盖。

[粘贴转写文本]
```

## 设计原则

Cyber Brain 不是“什么都记住”的聊天记录仓库，而是一个有取舍的个人记忆整理器。第一版不绑定数据库、向量库或音频服务，先用清晰的 Markdown/YAML 结构验证“什么值得成为我”。

它还有一个重要原则：可以什么都不记。只有会影响未来理解、决策或沟通的内容，才值得进入长期记忆。

## 一分钟 Demo：它为什么不是普通总结 Prompt

```text
一段很长、很乱的录音/聊天
        ↓
过滤寒暄、语气词、重复、跑题内容，但保留犹豫和观点转折
        ↓
形成少量结构化记忆：事件 / 原判断 / 新发现 / 我的观点 / 行动 / 待验证
        ↓
几个月后，用户又说：“我准备每天发五条，先把量堆起来。”
        ↓
Cyber Brain 找到过去的决定：曾因盲目追求数量而决定先控制频率
        ↓
它不会只说“可以试试”，而是指出相似之处，并建议先做小规模验证
```

普通总结只回答“刚才聊了什么”。Cyber Brain 还维护观点变化、证据来源和记忆生命周期，并在必要时让过去的用户参与现在的决定。

## 当前边界

它默认接收“录音转写文本”，不负责在本地自动转录音频。这样第一版更容易跨工具使用，也避免把工程复杂度误当成产品价值。

## 跨平台安装说明

核心逻辑在 `SKILL.md` 和 `references/` 中，平台适配只影响发现和安装方式：

- Codex：将整个文件夹放入可发现的 skills 目录。
- ChatGPT Skills：导入仓库中的 `SKILL.md` 及其引用文件；若平台不读取 `agents/openai.yaml`，可忽略该文件。
- WorkBuddy 或其他 Agent Skills 平台：按平台要求注册 `SKILL.md`，保留 `references/` 和 `examples/` 的相对路径。

不要把平台专属 API、数据库或 UI 逻辑写进核心 Skill；如果未来需要，新增单独的适配说明或可选目录。
